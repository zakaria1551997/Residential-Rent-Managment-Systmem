# উইন্ডোজ ক্লায়েন্ট ইনস্টলেশন ও ব্যবহার নির্দেশিকা (Windows Client Setup Guide)
**প্রতিষ্ঠান:** শহীদ সৈয়দ নজরুল ইসলাম মেডিকেল কলেজ হাসপাতাল, কিশোরগঞ্জ

---

### ১. ডেস্কটপ ক্লায়েন্ট ইনস্টলার তৈরি (.exe Installer Build)
উইন্ডোজ ডেস্কটপ ক্লায়েন্ট প্যাকেজ করতে মূল প্রজেক্ট রুটে চালান:
```bash
# ১. ফ্রন্টএন্ড বিল্ড
npm run build

# ২. উইন্ডোজ 64-বিট ইনস্টলার (.exe) তৈরি
npx electron-builder --win nsis
```
বিল্ড সম্পন্ন হলে `release/` ডিরেক্টরিতে ইনস্টলার ফাইলটি পাওয়া যাবে:
`SSNIMCH Residential Allocation System Setup 1.0.0.exe`

---

### ২. ক্লায়েন্ট পিসিতে ইনস্টলেশন প্রক্রিয়া
১. হাসপাতালে অবস্থিত যেকোনো উইন্ডোজ ১০/১১ কম্পিউটারে `SSNIMCH Residential Allocation System Setup.exe` ফাইলে ডাবল ক্লিক করুন।
২. স্ক্রিনের নির্দেশনা অনুসরণ করে ইনস্টল সম্পন্ন করুন। ডেস্কটপে স্বয়ংক্রিয়ভাবে শর্টকাট তৈরি হবে।
৩. অ্যাপ চালু হওয়ার পর লগইন স্ক্রিন বা উপরের ডানপাশের **"ল্যান নেটওয়ার্ক"** আইকনে ক্লিক করুন।
৪. হাসপাতালের মূল সার্ভারের লোকাল আইপি অ্যাড্রেস প্রদান করুন (যেমন: `192.168.1.100`) এবং পোর্ট `3000` দিন।
৫. **"পিং পরীক্ষা"** বোতাম চেপে সংযোগ নিশ্চিত করে সংরক্ষণ করুন।

---

### ৩. নিরাপত্তা ও সংযোগ সুরক্ষা
- ক্লায়েন্ট অ্যাপ থেকে সরাসরি কোনো ডাটাবেজ অ্যাডমিন পাসওয়ার্ড দরকার নেই।
- সকল তথ্যের আদান-প্রদান এন্ড-টু-এন্ড সেন্ট্রাল অথেন্টিকেশন টোকেনের মাধ্যমে নিরাপদভাবে সম্পন্ন হয়।
