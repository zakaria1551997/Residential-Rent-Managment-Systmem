# কেন্দ্রীয় ব্যাকআপ ও দুর্যোগ পুনরুদ্ধার নির্দেশিকা (Centralized Backup & Recovery Guide)
**প্রতিষ্ঠান:** শহীদ সৈয়দ নজরুল ইসলাম মেডিকেল কলেজ হাসপাতাল, কিশোরগঞ্জ

---

### ১. ব্যাকআপের গুরুত্ব ও কাঠামো
হাসপাতালের সকল বরাদ্দ রেকর্ড, বাতিল আদেশ, বাসিন্দা তথ্য এবং অডিট লগ একটি সমন্বিত রিকভারি সেট (Recovery Set) হিসেবে সংরক্ষিত হয়।

### ২. ম্যানুয়াল ব্যাকআপ গ্রহণ প্রক্রিয়া
১. সিস্টেমে সুপার অ্যাডমিন হিসেবে লগইন করুন।
২. বামপাশের মেনু থেকে **"১১. ব্যাকআপ ও রিস্টোর"** ট্যাবে ক্লিক করুন।
৩. উপরে ডানপাশের **"তাৎক্ষণিক সিস্টেম ব্যাকআপ গ্রহণ"** বোতামটি চাপুন।
৪. মুহূর্তের মধ্যে সিস্টেম থেকে ক্রিপ্টোগ্রাফিক চেকমাসহ একটি এনক্রিপ্টেড ব্যাকআপ ফাইল (যেমন: `SSNIMCH_Backup_2026-10-15.json`) ডাউনলোড হবে।
৫. ফাইলটি নিরাপদ অফিস স্টোরেজ বা এক্সটার্নাল হার্ড ড্রাইভে সংরক্ষণ করুন।

### ৩. PostgreSQL স্বয়ংক্রিয় সিডিউল ব্যাকআপ (Windows Server Task)
উইন্ডোজ টাস্ক শিডিউলার (Task Scheduler) দিয়ে প্রতিদিন রাত ১২:০০ টায় স্বয়ংক্রিয় ব্যাকআপ স্ক্রিপ্ট চালান:
```powershell
$Date = Get-Date -Format "yyyy-MM-dd"
$BackupFile = "D:\SSNIMCH_Backups\ssnimch_db_$Date.dump"
& "C:\Program Files\PostgreSQL\15\bin\pg_dump.exe" -U ssnimch_user -h localhost -d ssnimch_db -F c -b -f $BackupFile
```

### ৪. দুর্যোগ পুনরুদ্ধার (Disaster Restore)
১. যেকোনো সার্ভার বা পিসি ক্র্যাশের পর নতুন ডিভাইসে অ্যাপ ইনস্টল করুন।
২. **"ব্যাকআপ ও রিস্টোর"** পেজে গিয়ে **"ব্যাকআপ ফাইল হতে রিস্টোর"** বোতাম চেপে ফাইলটি নির্বাচন করুন।
৩. প্রিভিউ উইন্ডোতে ভবনের সংখ্যা, কক্ষের সংখ্যা, বাসিন্দা ও বরাদ্দের সংখ্যা যাচাই করুন।
৪. **"হ্যাঁ, ডাটাবেজ রিস্টোর সম্পন্ন করুন"** বোতামে ক্লিক করুন। সম্পূর্ণ পূর্ববর্তী অবস্থায় সিস্টেম সাথে সাথে সচল হবে।
